개인정보처리방침

카톡 보관함 (개인용 카카오톡 백업 뷰어) · 시행일 2026년 9월 27일

1. 이 앱은 무엇인가요

카톡 보관함은 사용자가 자신의 Mac에서 만든 카카오톡 백업 보관함을 휴대폰에서 열어 보기 위한 개인용 웹 앱입니다. 운영자가 따로 있는 서비스가 아니며, 별도의 서버가 없습니다.

2. Google 계정 데이터 사용

  • 요청 권한은 https://www.googleapis.com/auth/drive.file 하나뿐입니다. 이 권한으로는 이 앱이 만든 Google Drive 파일(KakaoArchive 폴더)만 읽고 쓸 수 있고, 그 밖의 Drive 파일은 볼 수 없습니다.
  • 보관함 파일을 읽어 화면에 보여 주는 데에만 사용하며, 사용자가 표시한 “중요(★)” 정보는 같은 폴더의 user-state.json 파일에 저장합니다.
  • Google 사용자 데이터는 사용자의 기기와 사용자의 Google Drive 사이에서만 오갑니다. 제3자에게 제공·판매하거나 광고에 사용하지 않습니다.
  • 이 앱의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 기기에 저장되는 정보

설정 코드(Google 로그인 정보)와 최근에 본 보관함 내용의 캐시는 이 기기의 브라우저 저장소에만 저장됩니다. 앱의 “더보기 → 데이터 소스 변경/캐시 비우기”로 언제든 지울 수 있습니다.

4. 수집하지 않는 것

분석 도구, 광고, 쿠키 추적을 사용하지 않으며 사용 기록을 수집하지 않습니다.

5. 권한 취소

Google 계정 → 보안 → 타사 액세스에서 “카톡 보관함”의 접근 권한을 언제든 취소할 수 있습니다.

6. 문의

이 앱을 만든 사용자 본인이 관리합니다. Google Cloud 프로젝트에 등록된 지원 이메일로 문의하세요.
